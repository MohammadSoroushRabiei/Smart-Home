# جدول کامل پین‌های ESP32-S3-DevKitC-1 (N16R8)

منبع: شماتیک رسمی برد (`SCH_ESP32S3DevKitC1_V1_1_20221130.pdf`) + بررسی کد فعلی پروژه.

⚠️ **نکته‌ی مهم سخت‌افزاری:** این ماژول از نوع `ESP32-S3-WROOM-1-N16R8` است (۱۶ مگابایت فلش + ۸ مگابایت PSRAM). ظرفیت ۸ مگابایتی PSRAM روی این ماژول‌ها فقط با حالت **Octal SPI** پیاده می‌شود که ۳ پین اضافه (GPIO35، GPIO36، GPIO37) را به‌طور داخلی مصرف می‌کند. این پین‌ها **مطلقاً قابل استفاده به‌عنوان GPIO عمومی نیستند** — حتی اگر روی هدر بیرونی برد موجود باشند، استفاده از آن‌ها باعث از کار افتادن PSRAM و کرش کامل سیستم می‌شود.

## خلاصه

- **کاملاً آزاد و بدون دردسر (۵ پین):** GPIO21, GPIO39, GPIO40, GPIO47, GPIO48
- **آزاد ولی با محدودیت جزئی:** GPIO0, GPIO3, GPIO19, GPIO20, GPIO38, GPIO43(TX), GPIO44(RX), GPIO45, GPIO46(فقط input)
- **مصرف‌شده توسط پروژه‌ی فعلی:** GPIO1, GPIO2, GPIO4–GPIO18, GPIO41, GPIO42 (جمعاً ۱۹ پین)
- **کاملاً غیرقابل‌استفاده:** GPIO35, GPIO36, GPIO37 (رزرو PSRAM Octal)

## پیشنهاد برای قفل سلونوئیدی (بخش ۵)

بهترین گزینه‌ها برای رله‌ی قفل: **GPIO21، GPIO47، GPIO48، GPIO39، یا GPIO40** (همگی کاملاً آزاد و بدون هیچ محدودیتی برای output).
